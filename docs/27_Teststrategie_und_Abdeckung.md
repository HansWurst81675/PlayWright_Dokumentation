# Teststrategie und Abdeckung

## Ziel

Nicht jeder Ablauf benötigt einen UI-Test. Eine gute Strategie verteilt Tests auf verschiedene Ebenen.

## Testpyramide

### Unit Tests

Schnell und zahlreich.

### API Tests

Prüfen Services und Datenflüsse.

### UI Tests

Prüfen wichtige Benutzerabläufe.

## UI Tests auswählen

Geeignet:

- Login
- zentrale Geschäftsprozesse
- kritische Benutzerabläufe

Nicht geeignet:

- jede kleine Anzeige
- reine Layout-Prüfungen

## Abdeckung messen

Eine hohe Testanzahl bedeutet nicht automatisch gute Qualität.

Wichtig sind:

- kritische Funktionen abgedeckt
- Fehler werden erkannt
- Tests bleiben wartbar
