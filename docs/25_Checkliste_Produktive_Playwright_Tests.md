# Checkliste für produktive Playwright Tests

## Vor dem Schreiben

- Testziel klar definieren
- Benutzerablauf verstehen
- stabile Locators auswählen

## Während der Entwicklung

- Tests unabhängig halten
- keine unnötigen Wartezeiten verwenden
- Fehlermeldungen aussagekräftig prüfen

## Vor dem Merge

- lokal erfolgreich ausführen
- Trace bei Fehlern prüfen
- CI-Ergebnis kontrollieren

## Langfristig

- Testdaten pflegen
- veraltete Tests entfernen
- gemeinsame Funktionen kapseln

## Ziel

Eine gute Test-Suite soll Vertrauen schaffen und nicht zusätzliche Wartungsarbeit erzeugen.
