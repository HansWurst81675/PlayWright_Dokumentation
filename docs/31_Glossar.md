# Glossar

## Assertion

Prüfung eines erwarteten Zustands im Test.

## Fixture

Bereitgestellte Testumgebung oder Testressource.

## Locator

Beschreibung, wie ein Element gefunden wird.

## Page Object

Klasse zur Kapselung einer Webseite oder eines Bereichs.

## Trace

Aufzeichnung einer Testausführung zur Fehleranalyse.

## Worker

Prozess, der Tests parallel ausführt.

## Storage State

Gespeicherter Browserzustand mit Cookies und Local Storage.

## Flaky Test

Test, der nicht deterministisch erfolgreich oder fehlerhaft ist.
